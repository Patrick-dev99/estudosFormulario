# 🧾 Formulário com Validação

Este projeto é um **formulário interativo** desenvolvido para praticar validações no front-end, garantindo que os dados inseridos estejam corretos antes do envio.

## 🚀 Tecnologias Utilizadas

* **HTML5** — estrutura do formulário
* **CSS3** — estilo e layout
* **JavaScript** — validações em tempo real

## 🔍 Funcionalidades

* Validação de **CPF** conforme o formato e regra de dígitos verificadores.
* Validação de **senha** com requisitos mínimos de segurança.
* Exibição de mensagens de erro ou sucesso durante o preenchimento.
* Envio do formulário apenas quando todos os campos estão válidos.

✨ Projeto criado para treinar validações e aprimorar habilidades em JavaScript.
